## لماذا Invoy؟

ما تزال العديد من الشركات الصغيرة في الجزائر تحرّر فواتيرها في Word. يوفّر Invoy بديلًا عمليًا: تطبيق سطح مكتب **يعمل 100% دون اتصال** — بلا حساب، بلا خادم، بلا تخزين سحابي — بياناتك تبقى على جهازك. يتحدث البرنامج لغة الأعمال المحلية مباشرة: **المبالغ بالدينار الجزائري (DA)**، **الرسم على القيمة المضافة 19%**، **حق الطابع الجبائي**، المعلومات الجبائية (**رقم التعريف الجبائي NIF**، **الرقم الإحصائي NIS**، **رقم الاعتماد**، **رقم المقالة**)، واجهة **فرنسية / عربية (RTL)**، و**تصدير PDF صامت** بنقرة واحدة — دون أي نافذة طباعة.

## ✨ الميزات

### 📄 المستندات التجارية
- **فواتير مسبقة وفواتير** — ترقيم تلقائي لكل نوع مستند، الرسم على القيمة المضافة 19%، حق الطابع، المبلغ مكتوبًا بالحروف (المُقرَر)، مقاس A4 أو A5، خطوط وألوان قابلة للتخصيص
- **وسائل التسليم** — تخصم الكميات من المخزون تلقائيًا عند التصدير
- **وسائل الدفع** — نقدًا أو بشيك
- **برنامج التسليم** — نظّم جولة اليوم مع عدة عملاء، أوقات التسليم والمقالات لكل عميل
- **وسائل البضاعة** — سجّل مشترياتك وأضفها إلى المخزون
- **طلبيات الشراء** — مسودة ← مُرسلة ← مستلمة جزئيًا ← مستلمة، واستلام البضاعة يحدّث المخزون

<img src="docs/screenshots/stock-alerts.png" alt="Invoy — صفحة تنبيهات المخزون تعرض المنتجات ذات المخزون المنخفض أو المنتهي" width="880"/>

### 📦 المخزون
- كتالوج منتجات مع **كميات دنيا / قصوى**، أسعار الشراء والبيع، المورّد، ملاحظات
- حالة مباشرة لكل منتج — **سليم / مخزون منخفض / انتهى / مخزون زائد** — مع شارة تنبيه في الشريط الجانبي
- **سجل كامل للحركات** (دخول / خروج / تسوية) مع الأسباب: شراء، بيع، إرجاع، جرد، تلف
- حذف مستند **يُعيد الكميات إلى المخزون** (ضمن الكميات المتاحة) — يبقى السجل متسقًا

### 👥 العملاء
- ملف جبائي كامل (NIF، NIS، رقم الاعتماد، رقم المقالة) يُطبع على المستندات
- **استيراد من Excel** مع ربط الأعمدة ومعاينة الأسطر الأولى
- **سجل مستندات لكل عميل** — أعد تحميل أي فاتورة أو وصل تسليم أو دفع بنقرة واحدة

### 🖥️ التجربة
- واجهة **فرنسية + عربية** بدعم كامل من اليمين إلى اليسار
- **الوضع الداكن**
- **تصدير PDF صامت** عبر WebView2 `PrintToPdf` — مباشرة إلى الملف دون نافذة حوار
- **تصدير DOCX** بمخطط مطابق تمامًا لملف PDF
- **نسخ احتياطي / استعادة بصيغة JSON** لنقل جميع بياناتك بين الأجهزة
- اختصارات لوحة المفاتيح، التحقق من المدخلات، تنسيق الأرقام الفرنسي (`1 450,00 DA`)

## 🧱 التقنيات المستخدمة

| الطبقة | الاختيار |
|---|---|
| إطار سطح المكتب | [Tauri 2](https://tauri.app) (خلفية Rust، مضيف واجهة WebView2) |
| الواجهة | React 18 · Vite 5 · Tailwind CSS 3 · Radix UI · lucide-react |
| المستندات | PDF عبر WebView2 `PrintToPdf` (Rust) · DOCX عبر `docx` · استيراد Excel عبر `xlsx` |
| البيانات | مخزن JSON محلي (`@tauri-apps/plugin-store`) — دون أي خادم |
| الاختبارات | Vitest — 86 اختبارًا (تحليل المبالغ، سجل المخزون، اللغات، التحقق…) |

## 🚀 البدء

**المتطلبات المسبقة**
- Node.js 18 أو أحدث
- Rust بالسلسلة `stable-x86_64-pc-windows-msvc` (تتطلب أدوات البناء MSVC على Windows)
- WebView2 Runtime (مثبّت مسبقًا على Windows 10/11 مع Edge)

```powershell
# تثبيت الاعتماديات
npm install

# التشغيل في وضع التطوير (إعادة تحميل فورية + نافذة Tauri)
npm run tauri:dev

# تشغيل اختبارات الوحدة
npm test

# بناء النسخة النهائية (مثبّتات MSI + NSIS)
$env:CARGO_BUILD_JOBS = '1'   # لتفادي نفاد الذاكرة على الأجهزة متعددة الأنوية
npm run tauri:build
```

تُنشأ المثبّتات في `src-tauri\target\release\bundle\` (`msi\` و `nsis\`).

## 🗂️ بنية المشروع

```
├─ src/                    # تطبيق React (صفحات، مكوّنات، أدوات)
│  ├─ pages/               # الفاتورة، العملاء، وصل التسليم، المخزون، …
│  ├─ electron-docx/       # مولّد DOCX (نفس مخطط PDF)
│  ├─ utils/               # المبالغ، اللغات، التحقق، مخزن المخزون، قوالب PDF
│  └─ __tests__/           # اختبارات Vitest
├─ src-tauri/              # خلفية Rust
│  └─ src/pdf.rs           # تصدير PDF صامت عبر WebView2 PrintToPdf
├─ public/fonts/           # خط Inter (لاتيني) + Tajawal (عربي)
└─ docs/screenshots/       # لقطات الشاشة المستخدمة في ملفات README
```

## 📝 ملاحظات

- **تصدير PDF متاح على Windows فقط** (يعتمد على WebView2)؛ تصدير DOCX يعمل أينما تعمل التطبيق
- جميع البيانات (العملاء، المستندات، المخزون، الإعدادات) محفوظة في ملف محلي — استخدم **الإعدادات ← النسخ الاحتياطي** للتصدير والاستعادة
- تعمل الواجهة أيضًا في متصفح عادي (`npx vite`) بفضل نسخة من الـAPI محفوظة في الذاكرة — مفيدة لتطوير الواجهة بسرعة
